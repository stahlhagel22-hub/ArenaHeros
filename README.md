# Arena Heroes: Tactical Combat

Browser-Prototyp für ein rundenbasiertes taktisches Arena-Spiel.

## Start

Im Projektordner ausführen:

```bash
py -m http.server 8000
```

Danach `http://localhost:8000/index.html` öffnen.

Der Prototyp besteht aus `index.html`, `style.css` und `game.js` und enthält eine 20×20-Arena, Editor, individuelle Einheiteninstanzen mit getrennten AP, ein Missionsziel mit HP, Knockback, Kollisionsschaden, Statusmarker, Grafik-Uploads und LocalStorage-Speicherung.
